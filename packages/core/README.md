# @lexfield/core

平台无关的领域核心:所有端(Web / 桌面 / Android / CLI)共用的记忆调度与业务逻辑。

## 模块

| 模块 | 职责 |
|---|---|
| `types.ts` | 领域模型:词条、卡片(word 级 + sense 义项级)、评分日志、设置 |
| `fsrs.ts` | **FSRS-6** 调度封装(官方 `ts-fsrs`):分级→目标记忆率映射、评分、可提取性、序列化 |
| `queue.ts` | 会话构建:学新 / 复习 / 混合;到期抽样按分级权重(难:中:易 = 3:2:1 默认);每日新词上限 |
| `questions.ts` | 出题引擎:自评卡 / 单选 / 多选;义项随机拆分;干扰项按词频邻近度 + 词性偏好采样;自动判分 |
| `session.ts` | 评分落地:卡片创建/更新、到期日负载均衡(`balanceDay`)、暂停/重置/分级 |
| `storage.ts` | 存储适配器契约 + 内存实现 + 直方图统计(各端各自实现 IndexedDB / SQLite / Room) |
| `sync.ts` | 云同步客户端:注册/登录/推拉(LWW 合并),对接 Cloudflare Worker API |
| `transfer.ts` | 导出/导入(版本化 JSON,合并或替换) |

## 记忆算法要点

- **FSRS-6**(21 参数默认权重,`enable_fuzz` + 同日学习步骤 1m/10m):连续答对 → 稳定性指数增长 → 间隔变长 → 出现频率自动下降;答错 → 稳定性骤降 → 短间隔重排进重学队列
- **手动分级**叠加在 FSRS 之上:简单/中等/困难 → 目标记忆率 `base±Δ`(默认 0.85/0.90/0.95)→ 越困难间隔越短、出现越频繁;混合队列抽样权重同样偏向困难词
- **义项级调度**:每个汉语义项可有独立卡片(独立 FSRS 状态与分级),测哪个义项只影响哪个义项
- **负载均衡**:长间隔的到期日在 ±1~2 天窗口内挪到已有复习数最少的一天,摊平每日负载
